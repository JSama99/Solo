| Area | Baseline | Defect / Opportunity | Hypothesis | Change | Measurement | Decision |
|---|---|---|---|---|---|---|
| Founder decision loop | Sprint phases already cover founder event → commitments → assignment → review/resolve → commit | Systems exist, but the player-facing chain is not yet proven as one memorable causal story | A single deterministic trace will expose where causality becomes unreadable or mechanically thin | Audit only | Full event-chain trace, first divergence, feedback surfaces touched | OPEN |
| Agent truth gap | Task/evidence model stores reported quality, actual quality, verification state, overclaim amount, evidence completeness | Strong hidden-truth architecture may be too dependent on explicit review screens and visible numbers | Better decision gameplay should make history/context matter before the truth is revealed | Audit only | Count decision points where agent history changes plausible action | OPEN |
| Overclaim vs uncertainty vs drift | Separate verification states exist for overclaim, drift detected, evidence incomplete, confirmed/verified | Distinctions exist in state but may collapse into similar player responses | Preserve different causes, risks, and downstream consequences per state | Audit only | Compare resolution options and downstream chains by state | OPEN |
| Hindsight | Deterministic precedent model records context and outcomes without consuming RNG | Precedent currently summarizes sprint-level conditions more strongly than agent-specific behavioral memory | Agent-specific precedent may increase trust judgment without exposing a simple rating | Audit only | Measure decisions where prior agent history materially changes interpretation | OPEN |
| Consequence propagation | Delayed effects, company flags, obligations, Tech.com/coverage, rivals, evidence, Hindsight all exist | Major events are not yet contractually required to touch a readable multi-system chain | A consequence-chain contract can prevent isolated stat-only outcomes | Audit only | Systems touched per major decision; chain depth; feedback latency | OPEN |
| Onboarding | Title → mode → setup → thesis → Garage → sprint phases | Setup exposes career length, product, doctrine before the first core trust decision | Faster path to assignment/report/review/judgment may improve first-session comprehension | Audit only | Time/actions to first assignment, report, evidence review, judgment, consequence | OPEN |
| Progression | Six facility tiers exist; only Garage and Loft are currently environment-available | Facility progression is presently stronger as unlock/cost progression than as changing founder-problem progression | Each tier needs a distinct decision-pressure contract, not just a new space | Audit only | New decision patterns/failure modes per tier | OPEN |
| Atlantis | Shared-world traversal and district presentation exist | Physical traversal is ahead of gameplay utility | Atlantis should only expand when a district creates decisions unavailable at the Founder Computer | Audit only | Unique actionable opportunities per district | OPEN |
| Replayability | Daily seed, bounded/continuous modes, doctrine, product type, rivals, divergence, Hindsight, procedural task/result systems exist | Breadth of systems does not prove absence of dominant strategies | Deterministic repeated-seed decision analysis can reveal dominant patterns | Audit only | Repeated-choice rate; dominant-strategy rate; multiple-plausible-action rate | OPEN |
| Mobile pacing | Founder Desk consolidates primary interaction surfaces | Core simulation remains multi-step and potentially cognitively expensive | Strong state recall + one clear next action can preserve depth without spreadsheet feel | Audit only | Re-entry comprehension; time to identify next action; time to explain prior outcome | OPEN |
