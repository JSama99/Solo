# Shipathon Judge Access

1. Launch SOLO: Unicorn Run. No account or sign-in is required.
2. Start a career and complete Venture 1's twelve sprints; Venture 1 is free.
3. At the saved Founder Pass boundary, choose **Unlock Venture 2**.
4. Complete the non-consumable purchase using Apple's sandbox environment; no
   real charge is made.
5. Venture 2 resumes once. Hindsight Recall appears when prior conditions match,
   and the complete career conclusion becomes available.
6. To test an existing purchase, choose **Restore Purchases** on either Founder
   Pass screen.

No hidden review mode, password, secret gesture, or hardcoded entitlement is
included. If event timing requires faster legitimate access, the organizer may
issue an official App Store promo code or RevenueCat promotional entitlement and
revoke it afterward; distribute it privately, never in the repository.
