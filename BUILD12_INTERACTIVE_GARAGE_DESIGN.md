# Build 12 Interactive Garage Design

The Garage consolidates founder-event, assignment, review, and commit controls onto the desk and agent stations. `GarageTurnGate` is a pure mapping from persisted sprint phase to actionable surfaces, retaining visible but disabled unavailable objects. The desk uses the established dilemma, objective, intent, attention, and commit controls; station sheets use existing assignment, swap, review, and resolution callbacks. No simulation or RNG logic changes.
